# 🛒 Toy Store E-Commerce Analysis

## 📌 Project Overview

This project analyzes e-commerce website activity and sales data
from the Maven Fuzzy Factory dataset.

The goal is to understand website traffic, customer conversion,
marketing channel performance, and revenue trends using SQL and
Power BI.

## 🎯 Business Questions

1. What is the trend in website sessions and order volume?
2. What is the session-to-order conversion rate and how has it changed?
3. Which marketing channels have been most successful?
4. How has revenue per order evolved?
5. How has revenue per session evolved?
